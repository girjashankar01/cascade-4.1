# Frontend scaffold

React + TypeScript + Vite. The landing page identifies the DAO Accountability
Engine and Stage 0. No dashboard, wallet connection or accountability workflow
is implemented.

From this directory:

```powershell
npm ci
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
npm run build
npm run lint
```

See the root README for full project setup and handoff.md for validation results.
